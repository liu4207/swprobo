# 🤖 Sweeping Robot - Hardware Design

This folder contains the complete hardware design files for the smart sweeping robot, including schematic diagrams, PCB layout, BOM, and Gerber files. Designed using JiaLiChuang EDA (LCSC / EasyEDA).

📁 本目录为智能扫地机器人项目的硬件设计部分，包括原理图、PCB图、Gerber制造文件和BOM贴片资料。

---

## 🧩 Project Overview 项目概述

The robot is designed based on STM32F407, integrating motor control, sensor communication.

> 本机器人硬件系统基于 STM32F407，支持电机驱动、串口通讯等功能。
